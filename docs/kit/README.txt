里面有这些文件，按顺序这样用：

1. 打开豆包，新建对话（用「AI 编程」或普通对话都行）
2. 上传 snapshot.html、spec.md，以及 fullpage-desktop.png（有 fullpage-mobile.png 也一起传）
3. 打开 prompt.txt，把全文复制粘贴进对话框
4. 如果豆包问 tokens.json，再把它也传上去
5. 等它输出完整的 HTML，复制保存成 index.html，双击就能在浏览器里看

提示：
- 一次不行就追问「按 spec.md 第 3 节重做这一块」
- 颜色不对就说「只用 tokens.json 里的 hex 值」
- 手机端排版乱了就说「按 375px 宽度重排，不要横向滚动」

注意：这是用于「看效果 / 参考」的复刻版，不含真实后台，
不能直接拿去上线。正式交付请使用完整项目源码。
