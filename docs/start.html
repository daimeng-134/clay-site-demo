为什么不能直接把网址丢给豆包？
模型抓网址只能拿到未渲染的 HTML 文字，拿不到样式表和图片，复刻出来大概只有三四成像。 素材包把样式、图片、字体全内联进去了，还原度能到九成。

!事先说清楚

豆包产出的是单文件静态页面，用于看效果、做参考。它没有后台、没有表单接收、 不能改文案（改一个字要重新生成），也不含真实案例内容。

要真正上线、要能长期维护，用的是完整项目源码 —— 那套东西是 content/*.ts 改文案、brand.css 改配色、npm run build 出静态包。
