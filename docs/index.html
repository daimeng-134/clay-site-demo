合作原则

先说清楚，再签合同

定制开发最容易出事的地方不在技术，在预期。这四条是我们愿意写进合同的前提。

报价按工作量，不按预算倒推

先摸清需求再给数字，给的是一份分项的工作量估算，你能看到每一块花在哪里。不做「先报个低价再慢慢加」的事。

验收标准在开工前写进合同

每个功能点对应一条可验证的验收条件。到验收那天，双方对照这张表打勾，不靠感觉争论。

源码和数据都是你的

交付包含完整源码、数据库结构文档与部署说明。不上锁、不留后门、不绑定我们的服务器。

做不完的部分直说

如果评估后发现某个需求在我们的能力或时间之外，第一次沟通就会讲清楚，而不是签了合同再想办法。

先说说你现在怎么干活的

第一次沟通免费。两小时内告诉你这事能不能做、大概多少工作量、有没有更省的路子。就算最后不合作，这份判断也归你。
